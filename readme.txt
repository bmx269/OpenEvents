A fast, open-source events calendar. Add events to a dedicated post type or to the post types you already use.

== Description ==

Open Events Calendar adds events, venues, organizers, and calendar views to WordPress.

* Use a dedicated Events post type, add event dates to existing post types, or both.
* Month and list views that work without JavaScript and become an agenda list on phones.
* Category colours with a legend.
* iCal feeds and "Add to Google Calendar" links.
* Site Editor templates for block themes and fallbacks for classic themes.
* REST API, Abilities API, Block Bindings, and hooks for developers.

Built for sites with thousands of events: listings run indexed queries against a dedicated table and load everything they show in a fixed number of queries.

== Installation ==

1. Install and activate the plugin.
2. Follow the setup wizard to choose where events live and where the calendar appears.
